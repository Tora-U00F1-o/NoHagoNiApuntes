rutas-y-nodo-de-contexto§Ruta absoluta§/biblioteca/libro parte del documento y recorre biblioteca antes de libro.§/libro selecciona los libros hijos de biblioteca aunque omita biblioteca.§El documento tiene raíz biblioteca y se consulta /libro.§La ruta omite el elemento documento real y no alcanza esos libros.§La ruta es equivalente a /biblioteca/libro.
rutas-y-nodo-de-contexto§Descendientes§X//Y busca descendientes Y de X; X/Y busca hijos Y directos.§X/Y y X//Y seleccionan siempre exactamente los mismos nodos.§Un Y está dentro de Z, que es hijo de X.§X//Y puede alcanzarlo mientras X/Y no lo selecciona como hijo directo.§Ambas rutas lo seleccionan necesariamente como hijo directo.
rutas-y-nodo-de-contexto§Nodo y padre§El punto representa el contexto y dos puntos representan su padre.§El punto representa siempre la raíz y dos puntos representan un atributo.§El contexto actual es un elemento autor y se evalúa ..§La selección asciende a su padre.§La selección desciende al texto de autor.
rutas-y-nodo-de-contexto§Atributos§@id selecciona un atributo y no un elemento hijo id.§@id y el paso id seleccionan necesariamente el mismo tipo de nodo.§Un libro contiene atributo id y elemento isbn.§@id selecciona la identidad como atributo.§@id selecciona el elemento isbn automáticamente.
rutas-y-nodo-de-contexto§Comodín§En el paso de hijos mostrado, * selecciona elementos hijos, no atributos ni todo tipo de nodo.§El comodín * del paso hijo incluye automáticamente todos los atributos.§Un libro tiene cinco hijos y un atributo id; se evalúa libro/*.§Se seleccionan sus elementos hijos, excluyendo el atributo.§El atributo id se añade como sexto resultado del comodín.
rutas-y-nodo-de-contexto§Texto§text() selecciona nodos de texto; no es el mismo test que *.§text() selecciona únicamente elementos que se llaman text.§Se necesita distinguir nodos de texto y elementos hijos.§Deben distinguirse text() y *.§Ambas expresiones son sinónimos universales.

predicados-y-orden-de-los-filtros§Filtro y paso§Un predicado filtra nodos del paso y no añade un nivel de hijo.§Cada predicado entre corchetes crea un nuevo elemento descendiente.§Se compara libro[2] con libro/autor.§El primero filtra libros y el segundo recorre hacia autores.§Ambos añaden exactamente el mismo nivel de hijo.
predicados-y-orden-de-los-filtros§Orden de filtros§X[1][@Y='Z'] filtra primero por posición y después por atributo.§Cambiar el orden de predicados es siempre irrelevante.§El primer X no tiene Y='Z', pero el segundo sí; se evalúa X[1][@Y='Z'].§No queda seleccionado el segundo X por ese filtro.§El segundo X se selecciona porque el atributo prevalece sobre la posición previa.
