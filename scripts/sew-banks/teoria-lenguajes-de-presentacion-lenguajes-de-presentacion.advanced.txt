css-level-3-y-la-arquitectura-modular§Dos módulos CSS empiezan en niveles 1 y 3. ¿Qué explicación corresponde al material?§El nuevo puede empezar en 1 y el que actualiza CSS 2.1 en 3.§Todo módulo de CSS3 debe empezar en 3 sin excepción.§El módulo 1 solo puede pertenecer al CSS1 de 1996.§El módulo 3 debe contener toda la especificación CSS en un documento único.§Los niveles diferentes invalidan necesariamente ambos módulos.§La arquitectura modular admite numeraciones iniciales diferentes según exista o no antecedente en CSS 2.1.
por-que-no-existe-un-css-level-4-global§Color y Selectors alcanzan nivel 4. ¿Qué no se deduce de esa información?§Que exista una especificación global CSS4 con todos los módulos en nivel 4.§Que algunos módulos evolucionen independientemente.§Que haya niveles propios de módulo.§Que CSS3 describa una arquitectura modular.§Que deban consultarse los estados de módulos concretos.§Los niveles de módulos no forman necesariamente un número de versión global de toda la tecnología.

niveles-en-lugar-de-versiones§¿Qué diferencia hay entre nivel CSS y revisión de CSS2 en la exposición?§Los niveles amplían/refinan y 2.1/2.2 son revisiones del nivel 2.§2.1 y 2.2 son necesariamente dos módulos nuevos de nivel 1.§Cada revisión implica borrar todo lo definido en el nivel 2.§Las revisiones son sinónimos de fechas de fundación del W3C.§No existe relación entre CSS2 y CSS 2.1.§La unidad distingue evolución por niveles, revisiones para problemas del nivel 2 y posterior modularización.
principios-de-diseno-de-css§Un sitio reutiliza una hoja pero bloquea el uso con tecnología de apoyo. ¿Qué evaluación es correcta?§Reutilización lograda no demuestra por sí sola accesibilidad.§La hoja compartida acredita todos los ocho principios.§Toda hoja externa es necesariamente inaccesible.§El problema es imposible si los colores están centralizados.§La accesibilidad se define solo como cantidad de páginas que comparten CSS.§Los principios están relacionados pero son evaluables por separado; compartir reglas no elimina automáticamente barreras para usuarios.
