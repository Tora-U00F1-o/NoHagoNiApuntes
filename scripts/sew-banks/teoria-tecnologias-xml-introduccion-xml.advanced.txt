elementos-y-atributos§Se compara <p a="1" b="2"/> con <p b="2" a="1"/>. ¿Qué cambia necesariamente en la jerarquía XML?§Nada por el mero cambio de orden de atributos.§El último atributo pasa a ser hijo del primero.§La raíz se convierte en dos raíces.§Se pierde automáticamente la buena formación.§El elemento cambia su nombre de p a b.§El orden de atributos no modifica la jerarquía padre-hijo ni el nombre del elemento.

prologo-cuerpo-y-comentarios§¿Cuál es la restricción decisiva para un comentario XML con una secuencia -- en su interior?§La secuencia interior está prohibida, aunque el comentario tenga delimitadores de inicio y fin.§Es válido siempre que esté después de la raíz.§Es válido únicamente con encoding="UTF-8".§Se convierte automáticamente en CDATA.§Solo es inválido si además existe una DTD.§Cerrar un comentario no autoriza la secuencia -- dentro de él; tampoco se admiten comentarios anidados.
buena-formacion-y-validez§Un archivo tiene todos los cierres correctos pero una DTD exige precio y el archivo lo omite. ¿Qué diagnóstico es exacto?§Puede estar bien formado y no ser válido respecto de esa DTD.§No puede estar bien formado porque toda omisión gramatical es error de cierre.§Es válido por contener una sola raíz.§La DTD debe insertar siempre cualquier elemento obligatorio ausente.§El navegador decide validez solo por el aspecto visual.§Buena formación y cumplimiento de gramática son comprobaciones distintas; los elementos requeridos por una DTD pertenecen a la segunda.

prologo-cuerpo-y-comentarios§¿Qué interpretación evita confundir version, encoding y standalone?§Versión XML, codificación y dependencia de declaraciones externas son propiedades diferentes.§Encoding es el número de atributos y standalone el color de fondo.§Version fija el máximo de hijos y encoding selecciona SVG.§Standalone es siempre la URI del archivo XML.§Los tres son sinónimos de UTF-8.§La declaración XML describe propiedades del documento; no sustituye restricciones de contenido, estilos ni vocabularios.
elementos-y-atributos§Una ruta relativa cambia de base, pero el idioma no cambia. ¿Qué atributos deben distinguirse?§xml:base para base de rutas y xml:lang para idioma.§xml:space para idioma y xml:lang para base.§Encoding para base y version para idioma.§Precio para base y nombre para idioma.§Ambas propiedades se controlan exclusivamente con standalone.§xml:base, xml:lang y xml:space tienen funciones separadas y no deben intercambiarse por compartir el prefijo xml.

ventajas-y-limitaciones§Un XML describe instrucciones y el usuario espera ejecución automática sin intérprete. ¿Qué límite se está ignorando?§La representación declarativa de datos no ejecuta por sí sola un programa.§Todo XML es código máquina por ser legible.§Todo namespace identifica un servicio que ejecuta instrucciones automáticamente.§La extensión .xml implica ejecución en cualquier navegador.§Usar etiquetas en minúsculas activa un intérprete universal.§Describir una estructura o programa mediante XML exige un procesamiento que dé significado operativo a esos datos; el marcado solo no lo ejecuta.
